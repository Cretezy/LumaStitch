# Capability parity

This is the acceptance ledger for the expanded LumaStitch scope. A feature is complete only with an accessible editing workflow, saved projects, undo, machine-file verification, and an example. Algorithm benchmarks establish the measured cases only; they do not establish universal superiority or physical sew quality.

| Capability                     | Current evidence                                                                                                                                                                                                                                                                                                                                                    | Remaining acceptance work                                                                             |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| Running, satin, tatami routing | [Measured before/after](routing/README.md), [complete satin/tatami examples](stitch-examples/README.md), [connected centerline branches](satin-branches/README.md), [column splitting](satin-split/README.md), [variable-width rail routing](satin-rails/README.md)                                                                                                 | Broader real-design corpus and physical seam validation                                               |
| Lettering                      | [Editable text, kerning, multiline/circular layouts, monograms and batches](lettering/README.md); [path baselines](lettering-path/README.md); [TTF/OTF import, four bundled outline fonts and HarfBuzz shaping](opentype/README.md); [Unicode 17 mixed-direction layout](bidi/README.md); [three digitized fonts with 354 glyph entries](digitized-fonts/README.md) | Further commercial font coverage and physical sew-outs                                                |
