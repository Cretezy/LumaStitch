LumaStitch appliqué cutting package

Numbered pieces follow the current sewing sequence. Individual SVG/DXF files contain only closed cut contours, including holes. sheet.svg and sheet.dxf arrange pieces with 10 mm gaps; layout.svg adds numbers for reference only (do not send labels to a cutter). SVG dimensions are millimetres. DXF uses INSUNITS=4 (mm), CUT-layer closed polylines, and +y up. Confirm dimensions in the cutter application; disable automatic fit/scale.

The nominal fabric edge is the placement centerline, half the cover width inside the artwork boundary. Allowance offsets that edge; positive values enlarge fabric and shrink holes. Mirroring flips each patch horizontally, for backing-side cutting, without changing the sewing design. Patch allowance is independent of stitch pull compensation. Re-export after changing geometry or cover width.

Use the placement stop to position the patch. Enable Pre-cut fabric on appliqué objects to omit the trimming stop after tack-down. Omit covered satin removes only edges fully covered by later appliqué fabric; it leaves placement/tack-down complete. source.lumastitch preserves the sewing design and cutting settings. These are geometry exports, not cutter-specific machine commands. Verify a sample's cut size and registration before production.
