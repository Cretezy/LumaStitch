## Checklist for each test

1. Export from LumaStitch, then open the `.pes` in Ink/Stitch (or pyembroidery) and PE-Design or a Brother viewer. Note any errors.
2. Check the machine screen: label, colour count, size.
3. Sew. Photograph front and back.
4. Note puckering, gaps, visible travel, thread breaks and trims to do by hand.
