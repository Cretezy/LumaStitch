# LumaStitch: notes for coding agents

- Product spec: [SPEC.md](./SPEC.md). Architecture: [ARCHITECTURE.md](./ARCHITECTURE.md). Overview, screenshots and setup: [README.md](./README.md).
- **Keep these documents up to date.** When a change alters behaviour described in SPEC.md, an algorithm or structure described in ARCHITECTURE.md, or anything shown or explained in README.md (features, formats, setup, deployment, screenshots), update the document in the same change. Third-party code or data goes in NOTICE.md.
- Node lives under mise: prepend `~/.local/share/mise/installs/node/<version>/bin` to `PATH` if `node` isn't found.
- Checks before committing: `npx tsc -b`, `npx eslint .`, `npx prettier --check src e2e`, `npx vitest run`, `npm run build && npx playwright test`.
- README screenshots and the stitch-out animation are generated by `node scripts/readme-screenshots.mjs` (after `npm run build`); regenerate them when the UI or the stitch output visibly changes.
- Deployment: Cloudflare Workers Builds deploys every push to `main`.
- Version control: the repo is colocated with jj; commits and pushes only when asked.
